# AgentRunway

AgentRunway is the project name for this Elixir/OTP agent orchestration
learning system.

## Core Idea

AgentRunway is a supervised runway for AI agent work.

Issues arrive from a tracker, move into a queue, receive a workspace, launch as
agent runs, and then land as completed, failed, retrying, or blocked work. The
name fits because the interesting part of the project is not only the queue. It
is the full operational path from incoming issue to controlled agent execution.

## Why It Fits

- **Agent** points directly at the AI worker model.
- **Runway** suggests launch, flow control, sequencing, and operational safety.
- The name leaves room for the project to grow from a learning queue into a
  small agent runtime.
- It matches the current architecture: tracker polling, queue state,
  supervised workers, retries, blocked states, and per-issue workspaces.

## Tagline

An Elixir/OTP runway for supervised AI agent runs.
